Test it yourself / 30 seconds

Same URL, two outcomes. The user-agent decides.

# Browser-class request → 200, full article
$ curl -s -o /dev/null -w "%{http_code}\n" \
    https://edge.xenarch.dev/dispatch/the-toll-economy/
200

# Self-identifying agent → 402 with the x402 envelope
$ curl -s -A "GPTBot/1.0" \
    https://edge.xenarch.dev/dispatch/the-toll-economy/ | jq .
{ "x402Version": 1, "accepts": [ ... ], "xenarch": true,
  "price_usd": "0.01", "verify_url": "...", "facilitators": [ ... ] }

# Pay the voucher, retry with X-Payment → 200. That's the rail.
